# Model credits

All models in this folder are original and generated procedurally in Blender by the scripts in
`tools/models/` (geometry, rig, animation and baked textures). No third-party assets, textures or
HDRIs are used.

| File | Source | Licence |
|---|---|---|
| scavenger.glb | `tools/models/scavenger.py` | same as this repository |
| hands.glb | `tools/models/hands.py` | same as this repository |
| debris.glb, crate.glb, console.glb | `tools/models/props.py` | same as this repository |
| items/*.glb (+ icons in `public/icons/items/`) | `tools/blender/items.py` | same as this repository |

If you add downloaded assets (e.g. CC0 from Poly Haven, ambientCG, Kenney or Quaternius), list each
one here with its URL, author and licence.
